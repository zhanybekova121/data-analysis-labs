## 2. Теоретическая часть

### 2.1. Индексация и срезы

```python
sales = np.array([100, 150, 120, 180, 200])

sales[0]
sales[-1]
sales[1:4]
sales[::2]
sales[::-1]
```

Срез `start:stop:step` выбирает элементы с заданным шагом. Правая граница `stop` не включается.

### 2.2. Индексация двумерных массивов

```python
sales = np.array([
    [100, 120, 150],
    [80, 110, 140]
])

sales[0, 1]
sales[:, 1]
sales[1, :]
```

Для матрицы «регионы × недели»:

- `sales[0, :]` — все недели первого региона;
- `sales[:, 1]` — продажи всех регионов за вторую неделю.

### 2.3. Булевы маски

```python
revenue = np.array([1000, 2500, 800, 4000])

revenue > 2000
revenue[revenue > 2000]
```

Маска содержит значения `True` и `False` и позволяет отбирать элементы без циклов.

Для составных условий используйте `&`, `|` и `~`. Каждое сравнение в составном выражении следует заключать в скобки.

```python
mask = (revenue > 1000) & (revenue < 4000)
```

### 2.4. Вычисляемые условия

```python
profit = np.array([200, -50, 400, 0])

loss_mask = profit < 0
```

Булевы маски позволяют выделять убытки, подозрительные значения и сегменты, соответствующие заданным критериям.

Для выбора значения по условию можно использовать `np.where()`:

```python
status = np.where(profit < 0, "Loss", "Non-loss")
```

```python

order_id = np.arange(2001, 2013)

    "Bishkek", "Osh", "Bishkek", "Karakol", "Osh", "Tokmok",
    "Bishkek", "Osh", "Karakol", "Tokmok", "Bishkek", "Osh"

quantity = np.array([2, 1, 5, 3, 2, 8, 1, 4, 2, 3, 6, 1])

unit_price = np.array([
    1500, 20000, 800, 5000, 1200, 700, 25000, 3000, 4500, 2000, 900, 18000
])

discount = np.array([
    0.05, 0.10, 0.00, 0.15, 0.05, 0.20, 0.30, 0.10, 0.00, 0.05, 0.50, 0.10

unit_cost = np.array([
    1000, 16000, 600, 4000, 900, 500, 18000, 2200, 3500, 1500, 800, 14000

revenue = quantity * unit_price * (1 - discount)
profit = revenue - quantity * unit_cost
```

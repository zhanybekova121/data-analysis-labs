## 2. Теоретическая часть

### 2.1. Создание массивов

```python
import numpy as np

sales = np.array([12000, 15000, 18000, 14000])

# Основные способы создания массивов
np.array([1, 2, 3])
np.zeros((3, 4))
np.ones((2, 3))
np.arange(1, 11)
np.linspace(0, 1, 5)
```

- `np.array()` создаёт массив из переданных данных.
- `np.zeros()` и `np.ones()` создают массивы с заданными размерами.
- `np.arange()` формирует последовательность с указанным шагом.
- `np.linspace()` создаёт заданное количество равномерно распределённых значений.

### 2.2. Структура массива

```python
sales = np.array([
    [12000, 15000, 18000],
    [9000, 11000, 14000]
])

sales.ndim
sales.shape
sales.size
sales.dtype
```

- `ndim` — число измерений.
- `shape` — размер каждого измерения.
- `size` — общее количество элементов.
- `dtype` — тип элементов.

Размерность массива важна для последующих вычислений. Например, массив с формой `(2, 3)` содержит два региона и три периода, если именно так организованы исходные данные.

### 2.3. Изменение формы

```python
values = np.arange(1, 13)
matrix = values.reshape(3, 4)
```

Метод `reshape()` меняет форму массива без изменения количества элементов.

Условие корректности: $\prod_{i=1}^{n} d_i = \text{size}$, где $d_i$ — размеры нового массива.

### 2.4. Типы данных и пропуски

```python
quantity = np.array([2, 3, 4], dtype=np.int64)
price = np.array([1000.0, 1500.0, 2000.0])

np.issubdtype(quantity.dtype, np.number)
np.isnan(price)
np.isfinite(price)
```

В аналитических данных необходимо проверять типы, пропуски, бесконечные значения и допустимые диапазоны.

Важно: `np.isnan()` не работает напрямую с обычными строковыми массивами. Для числовых данных следует выбирать подходящие средства проверки.

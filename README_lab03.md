# Lab 03: Aggregation-axis

Статистический анализ продаж интернет-магазина по регионам с помощью NumPy (агрегация по осям, медиана, СКО, IQR, доли, динамика).

Решение: [lab03_aggregation_axis.ipynb](lab03_aggregation_axis.ipynb)

## Ограничения

- Циклы `for`/`while`, Pandas и ручной перебор элементов не используются — только векторизованный NumPy.

## Содержание

1. Сравнение регионов (сумма, среднее, медиана)
2. Анализ разброса (СКО, IQR, коэффициент вариации)
3. Поиск выбросов по правилу IQR
4. Структура выручки (доли, HHI)
5. Сравнение первых и последних 4 недель
6. Устойчивость результата к исключению выбросов
7. Критерий проблемного региона
8. Аналитическая записка
9. Дополнительное задание: ранжирование по разным метрикам

## Ключевые результаты

- Лидер по выручке — Karakol (29.9 %), но он же наименее стабилен (CV 13.9 %) из-за одного выброса (неделя 7 = 220).
- Исключение выброса не меняет рейтинг регионов.
- Проблемный регион по критерию (≥ 2 из 3 флагов: отставание роста, CV > 10 %, ≥ 4 спадов) — Tokmok.

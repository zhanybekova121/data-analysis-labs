## 2. Теоретическая часть

### 2.1. Основные статистические функции

```python
np.sum(x)
np.mean(x)
np.median(x)
np.min(x)
np.max(x)
np.std(x)
np.percentile(x, 90)
```

- Среднее характеризует арифметический центр данных.
- Медиана менее чувствительна к экстремальным значениям.
- Стандартное отклонение характеризует разброс.
- Процентили позволяют изучать положение наблюдений в распределении.

По умолчанию `np.std()` использует `ddof=0`, то есть рассчитывает стандартное отклонение генеральной совокупности. Для выборочной оценки часто используется `ddof=1`.

### 2.2. Агрегация по осям

```python
sales = np.array([
    [100, 120, 150],
    [80, 110, 140],
    [130, 160, 170]
])

np.sum(sales, axis=0)
np.sum(sales, axis=1)
```

Если строки соответствуют регионам, а столбцы неделям:

- `axis=0` — агрегирование по регионам для каждой недели;
- `axis=1` — агрегирование по неделям для каждого региона.

### 2.3. Процентили и межквартильный размах

```python
q1 = np.percentile(x, 25)
q3 = np.percentile(x, 75)
iqr = q3 - q1
```

Межквартильный размах характеризует центральные 50% распределения. Для предварительного поиска потенциальных выбросов можно использовать границы:

\[ Q_1 - 1.5 \cdot IQR,\quad Q_3 + 1.5 \cdot IQR \]

Выход за границы не означает автоматически ошибку данных.

### 2.4. Доли и относительные показатели

Долю группы можно вычислить как отношение её количества или суммы к общему значению.

```python
share = group_revenue / total_revenue * 100
```

Перед делением необходимо убедиться, что знаменатель не равен нулю.

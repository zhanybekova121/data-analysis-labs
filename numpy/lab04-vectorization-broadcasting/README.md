## 2. Теоретическая часть

### 2.1. Векторизация

Векторизация позволяет выполнять операции сразу над массивами, без ручного перебора элементов.
quantity = np.array([2, 3, 4])
unit_price = np.array([1000, 500, 800])

gross_sales = quantity * unit_price
Основные финансовые формулы:

$$
\text{Gross Sales} = \text{Quantity} \times \text{Unit Price}
$$

$$
\text{Revenue} = \text{Gross Sales} \times (1 - \text{Discount})
$$

$$
\text{Cost} = \text{Quantity} \times \text{Unit Cost}
$$

$$
\text{Profit} = \text{Revenue} - \text{Cost}
$$

Здесь Profit — валовая прибыль по товарам до прочих расходов, а не чистая прибыль компании.

### 2.2. Условные вычисления
status = np.where(profit < 0, "Loss", "Non-loss")
`np.where()` выбирает значения в зависимости от условия. Его можно применять для классификации результатов и построения простых сценариев.

### 2.3. Broadcasting

Broadcasting позволяет выполнять операции между массивами разных форм, если размеры соответствующих осей совпадают или одна из них равна единице.

Примеры:

- `(4, 3)` и `(3,)` — совместимы;
- `(4, 3)` и `(4, 1)` — совместимы;
- `(4, 3)` и `(4,)` — несовместимы;
- `(4, 3)` и `(4, 3)` — совместимы.

Сравнение начинается с последних измерений.

### 2.4. Сохранение размерности
region_mean = np.mean(sales, axis=1, keepdims=True)
deviation = sales - region_mean
Если `sales` имеет форму `(4, 6)`, то `region_mean` имеет форму `(4, 1)`. Broadcasting позволяет вычесть среднее соответствующего региона из каждого его недельного значения.

### 2.5. Процентное изменение

\[
\text{Change \%} =
\frac{\text{New} - \text{Old}}{\text{Old}}\times 100
\]

Если `Old = 0`, обычное процентное изменение не определено. Такие случаи необходимо обрабатывать отдельно.

    [12000, 15000, 18000, 21000, 19000, 23000],
    [9000, 11000, 14000, 16000, 13000, 15000],
    [20000, 22000, 19000, 25000, 24000, 26000],

target = np.array([15000, 16000, 17000, 18000, 20000, 22000])
